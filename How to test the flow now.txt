How to test the flow now
1.	Sign in as Alice Jacobs (u1), go to My Timesheet, fill 40h, Submit.
2.	Switch to Erin AECOM (Program Approver) (u5) — she has Jacobs in her ApproverScope — go to Approvals, and the submitted timesheet will now appear.
3.	Approve/Reject it — status persists to the JSON file immediately.
4.	You can also open %TEMP%\Timesheet.Web\timesheets.json directly and hand-edit entries/status while the app is stopped, then restart to load your edits.
Note: since the store is a singleton and the JSON file is written per save, concurrent edits while the app is running won't auto-reload — restart the app to pick up manual file edits.
